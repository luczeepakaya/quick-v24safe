Developer API Endpoints

Integrate universal social media video & audio downloading into your projects

POST /api/details

Extract metadata, thumbnail, author info, and direct downloadable media URLs from any social media link.

// Request Payload { "url": "https://www.tiktok.com/@user/video/..." } // Response { "platform": "tiktok", "title": "Awesome video title", "qualities": { "no_watermark": "https://...", "audio": "https://..." } }
POST /api/youtube

Generate direct high-speed download links for YouTube videos and audio up to 1080p.

// Request Payload { "url": "https://www.youtube.com/watch?v=...", "type": "mp4", // "mp4" or "mp3" "quality": "720p" // "360p", "480p", "720p", "1080p" }
